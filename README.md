# Sensora

Бесплатное PWA для создания комфортной звуковой среды и мягкой саморегуляции. Все данные пользователя остаются в браузере.

## Запуск

```bash
npm install
npm run dev
```

Проверка production-сборки: `npm run build`.

## Публикация на Vercel

Импортируйте репозиторий в Vercel. Команда сборки и папка результата уже указаны в `vercel.json`. Переменные окружения не требуются.

## Ассеты

- Фон: `public/assets/background.png`
- Логотип: `public/assets/logo.png`
- Встроенные записи: `public/audio/`

Приложение не является медицинским изделием и не заменяет профессиональную помощь.
